# Normas para Notas de Estudio

## Objetivo
Estas normas están diseñadas para asegurar que las notas de estudio sean claras, organizadas y útiles para el aprendizaje y la consulta futura.

## Estructura de las Notas
1. **Título**: Cada nota debe comenzar con un título que refleje el tema.
2. **Fecha**: Incluir la fecha de la sesión de estudio.
3. **Resumen**: Un breve resumen de lo aprendido.
4. **Conceptos Clave**: Listar los conceptos y definiciones importantes.
5. **Ejemplos**: Incluir ejemplos prácticos que refuercen el aprendizaje.
6. **Referencias**: Citar cualquier recurso adicional que se haya utilizado.

## Formato
- Utilizar Markdown para mantener las notas legibles y bien estructuradas.
- Usar listas y subtítulos para organizar la información.
- Emplear negritas y cursivas para destacar puntos importantes.
- Mantener los archivos de cada carpeta en el orden en que se crearon, ya que ese orden representa la secuencia de estudio del módulo. No ordenarlos alfabéticamente ni reorganizarlos; reflejar la misma secuencia en el árbol de archivos del README.

## Revisión
- Revisar las notas al final de cada sesión para asegurarse de que estén completas y claras.
- Considerar la posibilidad de compartirlas con otros para recibir retroalimentación.

## Actualización
- Mantener las notas actualizadas con nueva información y ejemplos conforme se avanza en el aprendizaje.
